# 🌐 معرض أعمال شخصي زجاجي (Glassmorphic Portfolio Page)

صفحة هبوط (Landing Page) شخصية ومودرن لمعرض أعمال (Portfolio)، مصممة بأسلوب الـ **Glassmorphism** (التأثير الزجاجي المقصوص مع بلر خلفية جذاب). الواجهة مجهزة بالكامل لتكون سريعة، خفيفة، ومتجاوبة مع تأثيرات حركية ناعمة.

---

## ✨ المميزات (Features)

* **تصميم زجاجي عصري:** استخدام تأثير `backdrop-filter: blur(30px)` مع خلفية شفافة وإطار هادي بيدي شكل زجاجي فخم للـ Container.
* **شريط تنقل ذكي (Navbar):** يحتوي على تأثير الـ Hover والـ Active لتحديد الصفحة الحالية بسلاسة.
* **تأثيرات حركية (Hover Effects):** الأزرار وأيقونات التواصل الاجتماعي بتتحول وتعمل إضاءة (Glow Effect) ناعمة باللون الأبيض عند مرور الماوس.
* **صورة شخصية دائرية:** صندوق الصورة مصمم بشكل دائرى متناسق وبحجم مرن (`28vw`) مع ظلال مميزة حوله.
* **أيقونات السوشيال ميديا:** دمج أحدث أيقونات `Font Awesome` (فيسبوك، إنستجرام، يوتيوب، ولينكد إن).

---

## 🛠️ التكنولوجيات المستخدمة (Technologies Used)

* **HTML5:** لبناء هيكل الصفحة والأقسام (Header, Navbar, Home Section).
* **CSS3:** لتطبيق التصميم الزجاجي، الـ Flexbox لترتيب العناصر، والـ Transitions للحركات.
* **Font Awesome (v6.4.0):** لعرض أيقونات منصات التواصل الاجتماعي بجودة عالية.
